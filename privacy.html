Privacy Policy

Homelab Automation — last updated 13 September 2026

Summary

This application is a personal, self-hosted automation project with a single user: its owner, Oscar Thiellier. It accesses only that owner's own Google account. No other person's data is processed, and there is no way for anyone else to sign up or connect an account.

What data is accessed

  • Gmail messages — read in order to prepare draft replies. Drafts are created in the owner's own mailbox and are only sent after the owner explicitly approves them.
  • Google Calendar events — read to check availability and detect conflicts; created, updated or moved only at the owner's request.

How the data is used

Solely to perform the action the owner asked for: drafting a reply, answering a question about the day's schedule, or adding an appointment. The data is not used for training, profiling, advertising, or analytics of any kind.

Where the data is processed and stored

On hardware in the owner's home. The application runs on a self-hosted server; speech recognition and language models run on local machines on the same network. Message and event contents are held in memory for the duration of a request and in the automation server's own execution history, which is pruned automatically after seven days.

No Google user data is copied to any third-party service, cloud provider, or analytics platform.

Sharing

None. Data is never sold, rented, shared, or transferred to anyone. There are no third-party processors, no advertising partners, and no subprocessors.

Retention and deletion

Automation run history is pruned automatically after seven days. Google account access can be revoked at any time by the owner at myaccount.google.com/permissions, which immediately and permanently ends the application's access.

Security

Credentials are held encrypted by the automation server and in a self-hosted password manager. Remote access to the environment is by VPN only. The application is not exposed to the public internet beyond the single callback address required to complete Google's sign-in flow.

Limited Use disclosure

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Any change to this policy will be published on this page with an updated date.
