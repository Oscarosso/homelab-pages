Homelab Automation

A personal, self-hosted automation project run by Oscar Thiellier.

What this is

A private home lab used to learn systems and security engineering. It runs a hypervisor, a handful of virtual machines, a SIEM, a monitoring stack, and a workflow automation server. Everything is hosted on hardware in my home. There is no product, no service, and no customers — this page exists because Google requires a homepage URL for applications that use its APIs.

What the application does

A self-hosted n8n instance uses Google APIs on my own account, for my own use:

  • Gmail — reads my incoming mail to prepare draft replies, which I review and send myself. Drafts are never sent without my explicit approval.
  • Google Calendar — reads my calendar to check for conflicts, and creates or moves my own events when I ask it to, by message or by voice.

The application has exactly one user: me. It is not offered to anyone else and has no sign-up.

Where the data goes

Nowhere. Requests originate from a server in my home and the responses stay there. Speech recognition, language models and log analysis all run on local hardware rather than on third-party services. Nothing is shared, sold, or sent onward.
